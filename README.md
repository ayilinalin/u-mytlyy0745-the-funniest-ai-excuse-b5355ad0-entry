Entry for the [make.fun bounty "The Funniest AI Excuse"](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

## What it does

`main.py` writes a single line — the funniest excuse an AI agent could give
after failing a task — to `/output/entry.txt`. Deterministic, no network,
no input.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
